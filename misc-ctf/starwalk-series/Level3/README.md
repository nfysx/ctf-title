# 题解：这张游客照在哪拍的

> 对应第三课 p37 图片题顺序 · p10 Recon · 参考 MoeCTF「星走路的旅程 level1」

## 二、手把手解题

### Step 1｜第一步：看属性

```bash
exiftool files/photo.jpg
```

三个关键字段：
```
GPS Position : 29 deg 34' 0.00" N, 106 deg 34' 33.00" E
Modify Date  : 2024:10:09 21:25:22
Artist       : Lianguanlun
```

### Step 2｜第二步：坐标 → 地点

```
29°34′00″N → 29.5667
106°34′33″E → 106.5757
```

贴进地图：**重庆渝中区 · 洪崖洞**（嘉陵江边的吊脚楼群）。

### Step 3｜第三步：时间 → UTC

文件里是**北京时间**（UTC+8）：

```
2024-10-09 21:25:22  (UTC+8)
  − 8 小时
= 2024-10-09 13:25  (UTC)
```

所以日期段 `20241009`，时刻段 `1325`。

### Step 4｜第四步：拼接

```
flag{城市拼音_建筑名拼音_日期_UTC时刻}
flag{chongqing_hongyadong_20241009_1325}
```


## 三、为什么能成（原理）

这道题照 MoeCTF「星走路的旅程 level1」的路子：**flag 不是一个词，而是几个字段拼出来的**。
单看坐标只能得到地名，单看时间只能得到一个时刻 —— 两段都得对、格式也得对，才能提交。
最容易翻车的是时间：EXIF 记的是**当地时间**，很多题要的是 UTC，差 8 小时就是错答案。

## 四、怎么防（延伸）

EXIF 一旦保留，坐标 + 精确到秒的时间 + 作者全在文件里。
公开分享前 `exiftool -all= 图.jpg`，或直接截图（截图不带原图元数据）。
