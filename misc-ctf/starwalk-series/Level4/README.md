## 二、手把手解题

### Step 1｜线索 1：老百货的招牌

画面左侧那栋被灯照亮的弧形建筑，顶部红色霓虹写着「**永安百货**」。

### Step 2｜线索 2：背后的高塔

它身后那栋带双尖顶的高楼，顶部招牌是「**SHIMAO 世茂**」。
两个都是上海南京东路一带的标志性建筑 —— 互相印证，不是巧合。

### Step 3｜线索 3：街本身

宽阔的步行街、两侧老字号与钟表店（画面右侧有 `MIDO` 表店招牌）——
这条街是**南京东路步行街**。

### Step 4｜拼出答案

```
城市拼音_街道名拼音_建筑名拼音
flag{shanghai_nanjingdonglu_yongan}
```


## 三、为什么能成（原理）

多步图寻题的解法是**交叉验证**：任何单一线索都可能误判（全国不止一家百货叫「永安」），
但三条独立线索同时指向同一个地点，结论就稳了。
实务上还会配合地图街景做最后确认：搜「永安百货 南京东路」，街景一看就对上。

## 四、怎么防（延伸）

同 p10：公开的照片会被用来做地理定位。发布前问自己一句
「这张照片里的招牌和地标，会暴露我在哪吗」。
