## 二、手把手解题

### Step 1｜看特征

只有 `0-9 a-f`，长度是偶数 —— 十六进制。

### Step 2｜转字节

```bash
python -c "print(bytes.fromhex('那串').decode())"
```

### Step 3｜和 base64 的区别

base64 是 3 字节 → 4 字符；hex 是 1 字节 → 2 字符。hex 更长，但一眼能对应到字节。


## 三、为什么能成（原理）

hex 是把每个字节拆成两个十六进制字符，长度翻倍但完全可逆。
你在 `xxd`、Wireshark 里看到的都是它 —— 记住 **两个字符 = 一个字节**。

## 四、怎么防（延伸）

hex 也只是表示法，不提供任何保密性，等同于明文。
