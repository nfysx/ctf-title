## 题面（直接复制到平台「简介」）

附件给了一个整数 `a` 和一个 61 bit 的素数模数 `m`，要找的是满足 `a*x ≡ 1 (mod m)` 的那个 `x`。`x` 的十进制写法就是 flag 花括号里的内容，附件只有 `files/task.txt`。

**提示**：模运算里没有除法，只有乘逆元；扩展欧几里得在求最大公约数时顺带就把它算出来了。

## 三、解题步骤

### 第 1 步：一行算出来

> Windows 上若没有 `python3` 这个别名（Microsoft Store 的占位别名会报 "Python was not found"），把命令里的 `python3` 换成 `python`。

Python 3.8+ 内置了模逆元，不用自己写循环：

```bash
python3 -c "a=314159265358979323; m=2305843009213693951; print(pow(a,-1,m))"
```

`pow(a, -1, m)` 返回满足 `a*x ≡ 1 (mod m)` 的唯一 `x ∈ [0, m)`；
底数与模数不互素时抛 `ValueError`，这本身就是一个有用的检查。

### 第 2 步：验算

```bash
python3 -c "a=314159265358979323; m=2305843009213693951; x=pow(a,-1,m); print(a*x % m)"
```

输出必须是 `1`。不是 1 说明参数抄错了（`m` 少一位、`a` 多一位都会全错）。

### 第 3 步：手写扩展欧几里得（理解它为什么成立）

不想依赖内置函数时，扩展欧几里得给出 `(g, u, v)` 使 `a*u + m*v = g = gcd(a, m)`。
`g = 1` 时两边对 `m` 取模，`m*v` 归零，剩下 `a*u ≡ 1 (mod m)`，所以 `u mod m` 就是逆元：

```python
def egcd(a, b):
    if b == 0:
        return a, 1, 0
    g, u1, v1 = egcd(b, a % b)
    return g, v1, u1 - (a // b) * v1

a, m = 314159265358979323, 2305843009213693951
g, u, v = egcd(a, m)
print(g, u % m)                     # g 必须是 1，第二项就是逆元
print((a * (u % m)) % m)            # 必须是 1
```

## 四、原理

**为什么逆元存在。** `a*x ≡ 1 (mod m)` 等价于存在整数 `x, y` 使 `a*x + m*y = 1`。
Bezout 定理说 `a*x + m*y` 能取到的最小正整值就是 `gcd(a, m)`，所以方程有解 ⟺ `gcd(a, m) = 1`。
模数是素数 `p` 时，只要 `a` 不是 `p` 的倍数就满足条件，逆元一定存在且在 `[0, p)` 内唯一。

**扩展欧几里得为什么能算出来。** 它是欧几里得算法的副产物：`gcd(a, m) = gcd(m, a mod m)`，
递归到 `gcd(g, 0)` 时可以直接写出 `g*1 + 0*0 = g`，再逐层回代把 `g` 表示成 `a, m` 的组合。
每一步的系数都是上一步系数的线性组合，所以栈深只有 `O(log m)`，61 bit 的模数十几层就到底了，
这就是为什么它比「从 1 试到 m」快得多（后者 `O(m)`，对 `2^61` 完全不可行）。

**为什么模逆元是密码学的零件。** RSA 的 `d = e^{-1} mod φ(n)` 是逆元；ElGamal/ECDSA 的签名里
`s = k^{-1}(h + r·d) mod n` 也是逆元；仿射密码 `E(x) = ax + b` 要求 `a` 在模 26 下可逆。
这些地方一旦逆元算错或模数选错（不互素），整套方案立刻崩掉。

## 五、防御建议

- 求逆元之前先确认 `gcd(a, m) = 1`：不互素时逆元不存在，硬算会得到错误结果或异常。
  很多实现事故就是把「模数不是素数」当成了「一定是素数」。
- 用库函数（`pow(a, -1, m)`、`gmpy2.invert`），不要在生产代码里手写循环；
  手写版本容易在负数取模、边界 `a = 0` 上出错。
- 模逆元常在密钥生成路径上，注意常数时间实现与错误信息：把「逆元不存在」和「算出来了」区分成不同报错，本身可能泄露信息。
- 别把「`a` 与 `m` 互素」当成安全前提：RSA 里 `e` 与 `φ(n)` 不互素只是密钥生成失败，但如果实现不检查，就会产出不可解密的密钥对。
